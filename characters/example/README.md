# Example Character Pack

This pack is a neutral template and a test fixture for the prompt engine and validator.

## Files

- `card.yml`: Identity, languages, speech rules and default reply length.
- `moods.yml`: Mood detection patterns, tone guidance, openers and endings.
- `lines.yml`: Fixed in-character lines for errors, limits, refusals and timeouts, and the line a chat sees when the
  core cannot be reached.

## Privacy

Real character packs are private and live on the host data volume, never in this repository.
