# ADR-0001: Build the Core as a TypeScript Service on Node 24

- **Date:** 2026-11-15
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

The core is a new TypeScript service on Node 24. The existing Python chatbot code is retired at cutover.

## Rationale

The designs AIRA adopts are proven in TypeScript, and both maintainers can read a small typed codebase.
