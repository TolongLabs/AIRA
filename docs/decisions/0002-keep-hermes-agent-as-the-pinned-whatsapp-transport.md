# ADR-0002: Keep Hermes Agent as the Pinned WhatsApp Transport

- **Date:** 2026-11-15
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

Hermes Agent stays as the WhatsApp transport at its pinned commit. It is not upgraded.

## Rationale

55 of 67 local patches fail on current upstream, and upstream ships the same WhatsApp library.
