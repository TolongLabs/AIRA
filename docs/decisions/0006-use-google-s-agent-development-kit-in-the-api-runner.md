# ADR-0006: Use Google's Agent Development Kit in the API Runner

- **Date:** 2026-11-15
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

The API runner uses Google's Agent Development Kit for the model loop and tool calls.

## Rationale

It gives callbacks at every stage the core must control, and the maintainers know it.
