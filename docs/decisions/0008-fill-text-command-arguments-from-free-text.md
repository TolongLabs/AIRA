# ADR-0008: Fill Text Command Arguments From Free Text

- **Date:** 2026-11-16
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

A text command names the tool and the model fills its arguments from free text. One command per message.

## Rationale

Nobody learns an argument syntax on a phone. The slash still guarantees which tool runs, and code still decides whether
it ran.
