# ADR-0020: Treat a Request With No Tools as an Auxiliary Chore

- **Date:** 2026-11-16
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

A request with no tools is an auxiliary chore, even when its text holds scope markers.

## Rationale

Measured: title and summary requests quote the transcript, markers included. Read as turns, they would answer a message
twice.
