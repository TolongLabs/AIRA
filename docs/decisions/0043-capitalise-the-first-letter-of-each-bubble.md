# ADR-0043: Capitalise the First Letter of Each Bubble

- **Date:** 2026-11-17
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

Code capitalises the first letter of each bubble, for every pack.

## Rationale

The owner wants replies to start with a capital. A speech rule alone left most example replies in lower case.
