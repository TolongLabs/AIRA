# ADR-0047: Draw Openers and Endings at Set Odds

- **Date:** 2026-11-17
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

An opener is drawn for about 1 reply in 3 and an ending for 1 in 4, never the one the chat saw last.

## Rationale

Measured in the simulator: with an opener and ending in every reply, "Hm, wait", "Ooh, okay" and "That's the catch"
became tics.
