# ADR-0049: Mark Used Sources and List Them in the Footer

- **Date:** 2026-11-21
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

The model marks used sources with `[sN]`. Cleaning strips the marks and lists those sources in the footer.

## Rationale

The footer credits the sources that informed the reply.
