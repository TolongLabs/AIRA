# ADR-0051: Make Both Footer Lines Italic

- **Date:** 2026-11-17
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)
- **Supersedes:** [ADR-0048](0048-write-the-tool-footer-in-superscript-with-source-domains.md)

## Decision

Both footer lines are italic. This replaces the superscript labels.

## Rationale

WhatsApp does not link a superscript domain, so the sources line stays in normal letters; the owner wants the two lines
to look alike.
