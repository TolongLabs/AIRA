# ADR-0065: Append and Read the PDF Offer in Code

- **Date:** 2026-11-17
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

The PDF offer is appended by code and its answer is read by code: a whole-message yes or `/pdf` from the requester
within 30 minutes.

## Rationale

The owner wants the offer mechanical, not left to prompt wording.
