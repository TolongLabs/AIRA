# ADR-0070: Label Replayed Replies That Code Wrote

- **Date:** 2026-11-17
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

A reply with no model call is replayed with a label saying code wrote it.

## Rationale

Measured: Taiga told a member she had made up a `/help` list that code wrote, because the history showed it as her own
words with no tool call.
