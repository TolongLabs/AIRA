# ADR-0097: Derive a Canonical Target From a Strict Post Shape on Unknown Hosts

- **Date:** 2026-11-21
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

A strict post shape on an unknown host yields a canonical platform target. YouTube stays host-only, and Facebook
requires long numeric or pfbid ids.

## Rationale

Mirror domains change faster than a host list.
