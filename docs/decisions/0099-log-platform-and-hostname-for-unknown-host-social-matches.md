# ADR-0099: Log Platform and Hostname for Unknown-Host Social Matches

- **Date:** 2026-11-21
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

Log the platform and hostname for a social path match on an unknown host.

## Rationale

Operators can measure recognition without logging post ids or links.
