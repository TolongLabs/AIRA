# ADR-0100: Find Social Links Three Quote Hops Back

- **Date:** 2026-11-21
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

Intake can find social links up to three user-message quote hops back in the same chat.

## Rationale

A reference can point to an earlier post without repeating its URL.
