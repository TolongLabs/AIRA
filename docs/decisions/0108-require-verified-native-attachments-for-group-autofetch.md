# ADR-0108: Require Verified Native Attachments for Group Autofetch

- **Date:** 2026-11-21
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

Group autofetch requires verified native attachment ownership and type. It excludes all YouTube forms.

## Rationale

Reader previews and covers can be displayed, but only verified post media can be sent to a group. See
[Autofetch](../trd/system.md#autofetch).
