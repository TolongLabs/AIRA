# ADR-0118: Give Each Platform Separate Read and Fetch Switches

- **Date:** 2026-11-22
- **Status:** Accepted
- **Group:** [Architecture](README.md#architecture)

## Decision

Give each supported platform separate read and fetch switches per chat.

## Rationale

Owners can opt out of one service while keeping others available.
