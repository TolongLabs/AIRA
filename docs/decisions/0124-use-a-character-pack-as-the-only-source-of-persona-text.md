# ADR-0124: Use a Character Pack as the Only Source of Persona Text

- **Date:** 2026-11-15
- **Status:** Accepted
- **Group:** [Data](README.md#data)

## Decision

A character pack on disk is the only source of persona text.

## Rationale

Persona text hard-coded in program code cannot differ per chat.
