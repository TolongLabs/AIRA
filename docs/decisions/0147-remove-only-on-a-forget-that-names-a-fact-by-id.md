# ADR-0147: Remove Only on a Forget That Names a Fact by ID

- **Date:** 2026-11-16
- **Status:** Accepted
- **Group:** [Data](README.md#data)

## Decision

Only a forget that names a fact by its id removes anything. A forget with words to search for returns the matches.

## Rationale

A search can match the wrong fact. The person, not a ranking, says which fact goes.
