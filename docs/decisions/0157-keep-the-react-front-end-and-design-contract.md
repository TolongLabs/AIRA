# ADR-0157: Keep the React Front End and Design Contract

- **Date:** 2026-11-15
- **Status:** Accepted
- **Group:** [Site](README.md#site)

## Decision

The owner site keeps its React front end and design contract. Chatbot pages call the core's API. Owner-tool pages keep
their current API.

## Rationale

It revamps the site without touching the owner tools.
