# ADR-0161: Show Up to Three Tool Footer Labels

- **Date:** 2026-11-22
- **Status:** Accepted
- **Group:** [Site](README.md#site)

## Decision

The tool footer shows up to three labels, then `+N`. This replaces the cap of two.

## Rationale

#261 asks for three. The card's own labels stay as written; a width budget with generic short labels was dropped as it
replaced persona wording.
